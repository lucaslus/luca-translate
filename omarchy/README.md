# Omarchy Native has moved

The native QML / Qt Quick plugin and independent Rust backend now live in
[**lucaslus/lucas-translate-omarchy**](https://github.com/lucaslus/lucas-translate-omarchy).

Use that repository for native installation, development, tests and releases.
It includes the required translation core source and builds without Tauri.
The plugin ID, native data paths and launcher names remain compatible with
existing installations.

This repository continues to provide the Tauri desktop application for macOS,
Windows and Linux, including the legacy Omarchy / Hyprland desktop integration
documented in [docs/OMARCHY.md](../docs/OMARCHY.md).
