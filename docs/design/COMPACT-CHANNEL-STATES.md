# 状态反馈与渐进展示

本规范取代此前“所有状态都收进可点击图标”的方案。必要信息与恢复操作默认可见；仅补充解释、诊断信息需要展开。

## 展示规则

- 首页：直接显示开始提示、四组快捷键，以及截图取字只复制文字的简短说明。保持输入焦点，无弹层。
- 权限：小锁图标、缺少什么权限、简短指引、直接可用的“打开设置 / 重启应用”。
- 渠道加载：渠道标题旁独立的 18px 圆环，不遮挡其他渠道，不占用空白正文。
- OCR / 历史 / 设置加载：小圆环加简短状态文字。空 OCR 返回必须结束等待，并直接提供重新截图。
- 渠道失败：统一布局，小图标、具体原因、恢复操作直接显示；不显示“没有完成”等无信息标题、不输出原始网络 URL。
- 限流：可见的冷却时间，到期仅恢复手动重试。其他渠道等待期间，重试按钮有禁用提示。
- 诊断信息：原生 details/summary 折叠，包括补充解释、状态码、复制诊断和日志入口。
- 历史、收藏、规则空态：直接显示对应说明；设置加载异常直接提供重新加载。
- 规则解释 info：保留为辅助说明，支持 hover 和键盘焦点；不承载主操作。

## 组件与性能

LucasState.create 默认返回内联内容；只有明确 compact:true 才显示无正文的小指示器。图标使用随包字体已有的语义图标（翻译、搜索、锁、断网、完成），没有可点击的 info 兜底，也不请求不存在的 states/*.png。

此轮没有新增角色插画；此前角色图集未作为合格透明资源交付。图标不是已批准角色素材的替代交付声明。

移除状态浮层、全局 MutationObserver、浮层定位和焦点抢占逻辑。原生诊断折叠在自己的卡片中；其中按 Escape 只折叠详情并回到 summary。加载尊重 reduced-motion，后台暂停动画。冷却计时共用一个定时器，窗口隐藏或没有倒计时则停止。

## 验证

真实 UI + 模拟 IPC 回归覆盖：初始引导无需点击、权限操作可见、各类错误恢复、渠道独立加载、单渠道重试、冷却、诊断隐私与 Escape、OCR 空返回、设置读取失败恢复、明暗主题与窄窗口无溢出。视觉截图需实际检查首页、权限、混合结果与多渠道失败。
