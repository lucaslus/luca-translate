# 整体 review 修复与验证（2026-09-04）

本轮在现有 OCR 权限修复之上实现，不重置 TCC、不删除用户配置/历史、不改变签名身份，也不引入新的前端框架。

## 修复范围

- **安全渲染**：移除动态 HTML/内联事件拼接，所有用户、OCR、渠道返回内容通过 DOM 文本节点显示；复制保留引号、换行和类似 HTML 的文字。启用 CSP，发音仅允许指定 HTTPS 端点。翻译、设置、选区窗口按职责分配 IPC 权限；识别文字只发送给主窗口。
- **请求生命周期**：每次翻译有独立 request ID，新任务取消旧任务等待，迟到的结果和 done 事件不会覆盖新结果。重复提交同一进行中请求合并；单渠道重试只调用该渠道并保留其他结果。取消、初始化失败、配置错误、超时都退出 loading，已完成的译文保留。
- **渠道调度与语言**：关闭的有道不再绕过开关查询；字典和普通渠道并发，不让慢字典阻塞其他结果。仅匹配语向时提供英文词典中文释义，其他语向不伪装成成功。尊重手动源语言，日文假名优先于汉字分类；自动推测明确标记。AI 地址校验准确识别 loopback，不能以路径含 localhost 绕过；不裁掉合法译文引号。
- **OCR 与划词**：保留 core-graphics 0.25 的 C bool ABI 修复。选区握手和提交带 capture ID，重复提交、取消后的迟到任务不能串结果；按鼠标所在显示器打开选区。截图完成后立即显示识别状态；支持取消等待和超时反馈。静默 OCR 使用系统通知和托盘提示，不抢焦点、不把识别正文写入通知。AX 所有权和返回类型检查修复；划词禁止重入，AX 有等待上限。
- **剪贴板**：macOS 保存各 item 的全部可物化类型，只有内容未再改变时立即恢复；不再先清空或延迟覆盖。数据无法完整保存或超过 32 MiB 时放弃模拟复制。Windows 使用 OLE 数据对象和 sequence number 保护多格式内容。Linux 仅读 PRIMARY，不再用可能损坏任意格式的 Ctrl+C 兜底。
- **配置与密钥**：共享配置通过互斥事务、同目录临时文件和原子替换保存；开关只更新一个字段，不用旧快照覆盖整个配置。不再重新添加用户删除的默认规则。API Key 使用系统凭据存储，前端只读到 `has_api_key`；留空保留、明确移除再保存。旧明文密钥写入凭据存储成功后才替换 JSON；迁移或配置落盘失败保留原文件与原密钥。已有凭据读取失败仅生成 AI 错误卡，不禁用免费渠道。已缓存密钥避免每次翻译重复读取钥匙串。
- **数据与设置交互**：历史/收藏按视图和请求代次接收，乱序返回不会改变删除目标。每页最多 100 条，支持加载更多；清空历史需确认，删除收藏可撤销。数据库错误返回 UI，不再静默吞掉。设置加载、保存、失败回滚均有状态；未保存 AI 输入不会被通知覆盖，关闭需确认。开机自启失败恢复原开关。
- **UI**：保留原有暖色/中性色风格，统一主窗口与设置的开关、按钮、焦点和错误提示；提高明暗主题对比度，长文本自动换行。权限页只保留“打开设置 / 重启应用”；没有第三个重试按钮。修复 AI 图片地址、缺失旋转动画、拼音未展示；补上可折叠按钮语义、键盘焦点、对话框取消和 reduced-motion。OCR 不被历史面板遮住，截图错误不停止无关翻译。
- **平台集成**：主程序的 macOS 专属窗口 API 已条件编译，接回真实 Windows/Linux 平台模块；增加三操作系统完整桌面构建 CI，避免只检查平台 stub 而漏掉主程序。

## 性能及等待上限

| 场景 | 当前策略 |
| --- | --- |
| 多渠道 HTTP | 全局最多 8 个 blocking 工作；每个渠道同时起跑，有空位才执行 |
| 取消翻译 | 立即停止 UI 等待和结果发布；已发出的同步 HTTP 不能强杀，直到渠道自身超时前仍占用工作槽，不会无限创建线程 |
| 翻译总体等待 | 后端 65 秒；前端 70 秒保护。渠道自身有请求超时 |
| 历史写入 | 第一个成功结果展示后异步保存，不阻塞其他卡片；一个完整查询只记一次，重试不重复记录 |
| SQLite | 单连接复用、WAL、2 秒 busy timeout，读写移出 UI 线程 |
| 选区初始化 | 5 秒握手保护；重复快捷键不重复创建窗口 |
| 截图 / OCR | macOS 截图子进程 8 秒；整体识别等待 25 秒。不可中止的 Vision 工作者仍占用唯一 OCR 槽，防止累积 |
| 划词 | AX 单次调用最多 0.8 秒；模拟复制最多等待 400ms，禁止并行操作剪贴板 |
| Linux 外部命令 | xclip 500ms；每次 tesseract 8 秒；超时终止并回收子进程，输出读取最多 1 MiB |
| 临时截图 | 私有临时目录，成功、失败与超时均清理，不留下可预测名称的图片 |

这些是代码中的资源/等待边界，不代表所有网络或 OCR 场景都达到某个实测响应时间。第一次凭据迁移可能出现系统钥匙串交互；配置损坏或迁移失败会明确报错，不能当作默认配置悄悄覆盖。
